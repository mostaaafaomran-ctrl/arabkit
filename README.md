# Clean and normalize Arabic text in one click

One-click Arabic text cleanup: strip diacritics/tatweel, normalize alef/yaa, convert digits, remove RTL marks and duplicate lines.

**Live:** https://mostaaafaomran-ctrl.github.io/arabkit/

- Runs fully in the browser, nothing uploaded, no signup
- Plain HTML/CSS/JS, no build step, no dependencies
- Arabic and English

## Run locally
Open `index.html` in a browser.

## Logic tests
`core.js` works in Node: `node -e "console.log(Object.keys(require('./core.js')))"`
